# Blur Filter

Applies a Gaussian blur directly to the image texture. `value` is the blur radius in pixels.

## Usage

```ts
import { Rect, Fills, Adjustments } from '@motionscript/sdk/v1';

Rect({
  width: 600,
  height: 400,
  fill: Fills.image('./photo.jpg', {
    fit: 'fill',
    preset: { adjustments: Adjustments.blur(8) },
  }),
})

// Raw object
preset: { adjustments: [{ type: 'blur', value: 8 }] }
```

## Props

| Prop | Type | Description |
|---|---|---|
| `type` | `'blur'` | Filter identifier |
| `value` | `number` | Blur radius in pixels |

## Notes

- Applied at the image texture level, before compositing.
- For blur on an entire node (including its children), use the [Blur Node Effect](../effects/implementations/blur) instead.
