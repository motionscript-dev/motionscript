# Curves Filter

Remaps pixel values along a smooth tone curve defined by control points. The renderer interpolates a curve through the points and applies it to the selected channel.

## Usage

```ts
import { Rect, Fills, Adjustments } from '@motionscript/sdk/v1';

// S-curve for contrast on RGB composite
Rect({ width: 600, height: 400, fill: Fills.image('./photo.jpg', {
  fit: 'fill',
  preset: { adjustments: Adjustments.curves({ points: [[0, 0], [0.25, 0.15], [0.75, 0.85], [1, 1]], channel: 'rgb' }) },
}) })

// Boost the blue channel only
preset: { adjustments: Adjustments.curves({ points: [[0, 0.1], [0.5, 0.6], [1, 1]], channel: 'b' }) }

// Raw object
preset: {
  adjustments: [{
    type: 'curves',
    points: [[0, 0], [0.5, 0.7], [1, 1]],
    channel: 'rgb',
  }],
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `type` | `'curves'` | – | Filter identifier |
| `points` | `[number, number][]` | – | Control points as `[input, output]` pairs in [0, 1] |
| `channel` | `'rgb' \| 'r' \| 'g' \| 'b' \| 'a'` | `'rgb'` | Channel(s) to apply the curve to |

## Reading the curve

Each control point is an `[input, output]` pair:

- `input`: the original pixel value (0 = black, 1 = white)
- `output`: the remapped value after the curve

A straight line from `[0,0]` to `[1,1]` is a no-op identity. Pulling points above the diagonal brightens; below darkens.

## Common recipes

### S-curve (contrast)

```ts
[[0, 0], [0.25, 0.15], [0.75, 0.85], [1, 1]]
```

### Lift shadows

```ts
[[0, 0.08], [0.5, 0.5], [1, 1]]
```

### Crush blacks

```ts
[[0, 0], [0.15, 0], [0.5, 0.5], [1, 1]]
```

### Orange-teal look (combine channels)

```tsx
Adjustments
  .curves({ points: [[0, 0], [0.5, 0.55], [1, 1]], channel: 'r' })   // warm reds
  .curves({ points: [[0, 0.05], [0.5, 0.5], [1, 0.95]], channel: 'b' }) // cool darks
```

## Animating

Control points interpolate linearly when tweened, so a `to` on the fill that carries the filter animates the curve. Both curve sets must have the same number of points:

```tsx
import { Fills, Adjustments } from '@motionscript/sdk/v1';

const graded = (points: [number, number][]) =>
  Fills.image('./photo.jpg', { fit: 'fill', preset: { adjustments: Adjustments.curves({ points, channel: 'rgb' }) } });

export default {
  kind: 'composition',
  nodes: [
    { id: 'photo', type: 'rect', parentId: null, layerOrder: 0,
      props: { width: 600, height: 400, fill: graded([[0, 0], [0.5, 0.5], [1, 1]]) } },
  ],
  commands: [
    // Lift the blacks and pull down the whites
    { id: 'fade-tones', type: 'to', targetId: 'photo', at: 0, duration: 1.5,
      args: { fill: graded([[0, 0.1], [0.5, 0.5], [1, 0.9]]) } },
  ],
};
```
