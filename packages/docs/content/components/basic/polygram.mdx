# Polygram

A star polygon. Alternates outer and inner vertices to form a star shape. Lower `ratio` values produce sharper, more pointed stars.

<PolygramCanvas />

## Usage

```tsx
export default {
  kind: 'still',
  nodes: [
    // Classic 5-pointed star
    { id: 'five', type: 'polygram', parentId: null, layerOrder: 0,
      props: { sides: 5, ratio: 0.4, width: 400, height: 400, fill: '#F5C26B' } },

    // 6-pointed star with rounded points
    { id: 'six', type: 'polygram', parentId: null, layerOrder: 1,
      props: { sides: 6, ratio: 0.5, width: 400, height: 400, fill: '#E8617C', cornerRadius: 8 } },

    // 8-pointed star with chamfered corners
    { id: 'eight', type: 'polygram', parentId: null, layerOrder: 2,
      props: { sides: 8, ratio: 0.6, width: 400, height: 400, fill: '#6990DD',
        cornerRadius: 12, cornerStyle: 'angled' } },
  ],
};
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `sides` | `number` | `5` | Number of outer points. Must be ≥ 3 |
| `ratio` | `number` | `0.5` | Inner-to-outer radius ratio (0–1). Lower values = sharper points. At `1` the shape degenerates into a regular polygon |
| `cornerRadius` | `number` | `0` | Vertex rounding radius applied to both inner and outer vertices |
| `cornerStyle` | `'rounded' \| 'angled'` | `'rounded'` | Vertex shape: circular arc (`'rounded'`) or chamfer cut (`'angled'`) |

## Animating

All props animate with a `to` command. Animate `ratio` to collapse points in or out, or `sides` to morph between star shapes:

```tsx
export default {
  kind: 'composition',
  nodes: [
    { id: 'star', type: 'polygram', parentId: null, layerOrder: 0,
      props: { sides: 5, ratio: 0.4, width: 400, height: 400, fill: '#F5C26B' } },
  ],
  commands: [
    // Collapse points inward
    { id: 'collapse', type: 'to', targetId: 'star', at: 0, duration: 1,
      easing: { kind: 'inOut' }, args: { ratio: 0.85 } },

    // Push them back out
    { id: 'expand', type: 'to', targetId: 'star', at: 1, duration: 1,
      easing: { kind: 'inOut' }, args: { ratio: 0.4 } },
  ],
};
```

## Notes

- `cornerStyle` takes a single scalar (not the per-corner shorthand from `Rect`) because star vertices don't map to named corners.
- `ratio: 1` degenerates into a regular polygon identical to `Polygon` with the same number of sides.
- The star is inscribed within the node's bounding rect, and outer vertices touch the rect edges.
