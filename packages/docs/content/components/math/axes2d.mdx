# Axes2d

An x and a y axis with ticks and numbers: the graph that plots, points and
arrows are drawn on. It ships in `@motionscript/math`; register the package's
`NODES` ([overview](/docs/components/math/overview)).

## Usage

```tsx
export default {
  kind: 'composition',
  nodes: [
    { id: 'axes', type: 'axes2d', parentId: null, layerOrder: 0,
      props: { width: 800, height: 450, padding: 32, xRange: [-7, 7], yRange: [-2, 2],
        xLabel: 'x', yLabel: 'y', fontFamily: 'Inter', end: 0 } },
    { id: 'sine', type: 'functionPlot', parentId: 'axes', layerOrder: 0,
      props: { expression: 'sin(x)', end: 0 } },
    // Any node inside the axes sits at graph x and y, at its own size.
    { id: 'note', type: 'text', parentId: 'axes', layerOrder: 1,
      props: { x: 1.57, y: 1.4, text: 'peak', fontSize: 22, fontFamily: 'Inter', fill: 'white' } },
  ],
  commands: [
    { id: 'axes-on', type: 'progressTo', targetId: 'axes', at: 0, duration: 1, args: { end: 1 } },
    { id: 'draw', type: 'progressTo', targetId: 'sine', at: 1, duration: 1, args: { end: 1 } },
    { id: 'zoom', type: 'rangeTo', targetId: 'axes', at: 2, duration: 1, args: { xRange: [0, 4] } },
  ],
};
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `xRange` | `[number, number]` | `[-5, 5]` | The x values shown, as `[min, max]` |
| `yRange` | `[number, number]` | `[-3, 3]` | The y values shown, as `[min, max]` |
| `xStep`, `yStep` | `number` | `0` | The spacing of each axis's ticks. `0` picks a tidy one for the axis's length |
| `xScaling`, `yScaling` | `'linear' \| 'log'` | `'linear'` | `'log'` spreads an axis by the decade and marks the powers of ten |
| `squareUnits` | `boolean` | `false` | Give a y unit the length of an x unit: `yRange` keeps its centre and takes the span that fits. Only when both axes are linear |
| `ticks` | `boolean` | `true` | Draw a tick at each step |
| `tickSize` | `number` | `10` | The length of a tick, in pixels |
| `labels` | `boolean` | `true` | Write the number at each tick |
| `labelSize` | `number` | `18` | The numbers' and titles' font size, in pixels |
| `labelColor` | `Color` | `'#9ca3af'` | The numbers' and titles' colour |
| `fontFamily` | `string` | `''` | The numbers' and titles' font |
| `xLabel`, `yLabel` | `string` | `''` | A title at the positive end of each axis |
| `stroke` | `Stroke` | `{ weight: 2, fill: '#9ca3af', endCap: 'triangle', capScale: 5 }` | The axis lines and their ticks. `endCap` is the tip at each axis's positive end; the ticks never take one |

`fill` paints a backdrop behind the box (none by default). `padding`
([layout](/docs/attributes/layout)) is the room between the box and the plot
area; a new `axes2d` in an editor starts with `32`. `start` and `end` trim the
axis lines, as on any [stroke](/docs/attributes/strokes).

## Commands

| Command | Args | Animates |
|---|---|---|
| `rangeTo` | `{ xRange?, yRange? }` | The window of values shown: a pan when a range's ends move alike, a zoom when they do not |
| `progressTo` | `{ start?, end? }` | Drawing the axes on. A tick and its number appear as the line reaches them; the titles appear when `end` reaches `1` |

```tsx
{ id: 'pan', type: 'rangeTo', targetId: 'axes', at: 0, duration: 1, args: { xRange: [-2, 12], yRange: [-1, 3] } },
```

## Notes

- Children sit in graph coordinates: a child's `x` and `y` are graph values,
  y up, and it keeps its own size. When `rangeTo` moves the window, a child stays
  on its graph point. That holds for any node, a shape, an image or a formula.
- Plots and marks (`functionPlot`, `pointsPlot`, `plotPoint`, `vectorArrow`,
  `vectorField`, `streamLines`, `tracedPath`, `dropLines`, `curveArea`,
  `riemannSum`) go inside a coordinate system: an `axes2d`, a `numberPlane`, a
  `numberLine` or a `polarPlane`.
- The axes cross at the origin while it is in range, and at the nearest edge
  otherwise. A log axis sits at the other axis's minimum. The value where the
  axes cross gets no tick and no number.
- Ticks, numbers and titles are drawn by the axes, not child nodes. An `xLabel` or
  `yLabel` written between dollar signs, `'$\\theta$'`, is typeset as a formula.
- Manim's `Axes`; `axes.plot` is a [FunctionPlot](/docs/components/math/function-plot)
  inside it, and a change of `x_range` is `rangeTo`.
- Related: [NumberPlane](/docs/components/math/number-plane) (axes over a grid),
  [NumberLine](/docs/components/math/number-line), [PolarPlane](/docs/components/math/polar-plane),
  [Axes3d](/docs/components/math/axes3d).
