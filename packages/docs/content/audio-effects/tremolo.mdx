# Tremolo

Modulates the clip's amplitude with a low-frequency oscillator (LFO), creating a rhythmic volume wobble. Classic uses include vintage electric-piano tremolo, radio-signal flutter, and pulsing ambient textures.

## Usage

```ts
import { AudioEffects, SoundNode } from '@motionscript/sdk/v1';

// Via AudioEffects builder — 5 Hz pulse at 60% depth
SoundNode({ src: './piano.mp3', effects: AudioEffects.tremolo({ rate: 5, depth: 0.6 }) })

// Via raw object
SoundNode({ src: './piano.mp3', effects: [{ type: 'tremolo', rate: 5, depth: 0.6 }] })
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `type` | `'tremolo'` | – | Effect identifier |
| `rate` | `number` | – | Modulation rate in Hz. How fast the volume pulses |
| `depth` | `number` | – | Modulation depth, `0`–`1`. `0` = no effect, `1` = volume dips fully to silence on each cycle |

## Animating

Ramp up the tremolo rate and depth over the clip:

```ts
import { AudioEffects, SoundNode, ramp } from '@motionscript/sdk/v1';

// Intensify the wobble over the first 4 seconds, then hold
SoundNode({
  src: './pad.mp3',
  effects: AudioEffects.tremolo({ rate: ramp(1, 8, 4).hold(), depth: ramp(0, 0.9, 4).hold() }),
})
```

An effect param is automated with a ramp rather than a tween: sound is scheduled once, ahead of playback, so a value written frame by frame never reaches it. See [Fades and automation](../attributes/audio#fades-and-automation) for how a ramp lines up with the clip.

## Notes

- The LFO shape is a sine wave: the amplitude rises and falls smoothly on each cycle.
- At very low rates (< 1 Hz) the effect acts as a slow volume swell rather than a noticeable wobble.
- At rates above ~20 Hz the modulation enters the audio-frequency range and the effect sounds like amplitude modulation (AM) distortion rather than tremolo.
- Both `rate` and `depth` accept a ramp.
